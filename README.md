# Windows claude image fixer
tool to convert clipboard images to real path in order to paste into claude.

# Run
1. Run the fixer (it's in sys tray)
2. Right click on the tray icon to enable or disable the tool
3. Take a snapshot (saves images to clipboard)
4. shift+ctrl+v to inside claude prompt (or any text editor) to get the path.
5. claude will recognize it as a path to an image and will display the [Image #] tag.
